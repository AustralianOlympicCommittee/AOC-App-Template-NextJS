## Support Level

Support level depends on the `classification.timeline` value in `app.yml`.

- `foundation`: best-effort support, expiry date required.
- `operational`: named owner, documented runbook and monitored deployment.
- `mature`: production support model, review date, monitoring and formal oversight evidence.
