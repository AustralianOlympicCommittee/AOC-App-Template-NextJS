# Oversight

This document records evidence for changes that require organisational oversight.

Oversight is not intended to block ordinary foundation work. It records the reason, owner and evidence for higher-risk changes.

## Oversight Required For

- Production deployment.
- External access.
- Public ingress.
- Custom domains.
- AOC-Sensitive data.
- Microsoft Graph permissions.
- Non-standard Entra app roles, assignment model or sign-in audience.
- Dedicated Lakebase projects.
- Shared Databricks datasets.
- Non-standard Azure resources.
